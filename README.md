# 📊 Adventure Works Sales Analysis – Power BI Dashboard

## 📌 Project Overview

This project is an **interactive Power BI dashboard** built using the **Adventure Works dataset**, designed to analyze **sales performance**, **customer behavior**, and **product trends**.  
The dashboard delivers **actionable insights** to support **data-driven business decisions**.

Adventure Works is a fictional manufacturing company, and this analysis focuses on understanding how sales vary across **regions**, **products**, **customers**, and **time periods**.

---

## 🎯 Objectives

- Analyze overall sales performance and revenue trends  
- Identify top-performing and underperforming products  
- Understand customer demographics and purchasing behavior  
- Track sales performance across regions and time  
- Support strategic decision-making using visual insights  

---

## 📊 Dashboards & Key Insights

### 🔹 Sales Overview
- Total revenue, profit, and order trends  

### 🔹 Product Analysis
- Best-selling products and low-performing items  

### 🔹 Customer Analysis
- Customer segmentation and contribution to revenue  

### 🔹 Regional Performance
- Sales distribution across regions  

### 🔹 Time-Based Trends
- Monthly and yearly sales comparison  

---

## 🛠 Tools & Technologies Used

- **Power BI Desktop**  
- **Power Query** – Data cleaning and transformation  
- **DAX** – Calculated measures and KPIs  
- **Adventure Works Dataset**
